動機

生成式 AI 已經能直接做出完整的歌曲，旋律可以很好聽，但成品有明顯的瓶頸。生成的歌曲帶著一種 AI 特有的殘響與空間感，編制和音色也很容易聽出 AI 的痕跡，做得再好，耳朵聽久了也會膩，而且很難做出新的聲響。

我想解決的是可控性。現在的音樂人一直在追求特殊的聲響，所以我讓 AI 與系統架構、專業軟體配合：把生成的歌曲拆成可以編輯的 MIDI、樂譜和 Logic 工程，人聲交給 Synthesizer V 這類以樂譜和參數驅動的歌聲合成軟體，每個音的音高、時間、發音都能逐一調整。

選擇以 Logic 為基礎，是因為每個音都能保持可以調整。透過一版一版的迭代開發，目標是讓第一版就能做得很漂亮。

這兩首作品的旋律都是我自己寫的，沒有只靠提示詞產生整首歌。Stay Right Here 的旋律與歌詞是我寫的，Love Beyond Reach Mvt. 1（Remix）的素材直接取自我的鋼琴三重奏《Love Beyond Reach》。

未來希望把這套流程做成免費、開源、每個人都能使用的工具，讓音樂人更快把想法變成可演奏的作品，對音樂產業有所貢獻。

系統架構

生成的歌曲經過分軌、轉 MIDI 與分析後，分成四條平行作業，經過驗收與聆聽回饋再進入下一版。點選圖中的步驟可展開細節。

  • Logic Pro
  • Synthesizer V
  • MuseScore
  • Python 分析工具
  • 生成的歌曲先透過插件分成人聲、鼓、貝斯、鍵盤、吉他等分軌，每條分軌再轉成 MIDI。
  • 歌詞的時間軸一起匯出，作為人聲逐字對位的依據。
  • 所有原始素材記錄來源與雜湊值，後面每一步都能回頭比對。
  • 拍號與小節線：有原曲樂譜時逐小節對位，沒有時由程式從低音、和聲與鼓偵測。Love Beyond Reach Mvt. 1（Remix）保留 4/4、5/8、6/8 的變換。
  • 和聲逐小節標記，之後直接寫進總譜的和弦記號。
  • 同類樂器多層分離：同一條分軌裡可能有兩件同類樂器在做不同的事。Love Beyond Reach Mvt. 1（Remix）的電吉他分軌其實是兩把，拆成 E.Gtr 1 主奏與 E.Gtr 2 副旋律後，與原曲逐小節吻合 70–100%。
  • 三條平行作業共用這一步的小節表，所以編曲、人聲與樂譜的小節號一致。
  • 只用已安裝的音色，例如 Steinway 鋼琴、Rhodes 電鋼琴與 Logic 電吉他音色鏈，不依賴付費外掛。
  • 寫成 Logic Pro 工程，每一軌保留可編輯的 MIDI，樂手或編曲者可以直接接手修改。
  • 歌詞用強制對齊逐字對回生成曲，再逐字檢查子音與氣音的起音位置。
  • Synthesizer V 重新演唱，逐音確認每個字都有發聲。
  • 換氣只縮短前一個音的尾巴，不移動下一句的起音，總譜同步標上換氣休止符。
  • MuseScore 產生總譜與主旋律譜，每小節都有和弦記號，同類樂器分在不同譜表。
  • 交付前跑同步檢查，比對譜上每個音與音檔的時間，不同步就不交付。
  • 樂譜與編曲、人聲平行進行，不必等混音完成。
  • 離線混音由 Python 程式完成，可以很快出試聽版，並量測與生成曲的頻段差距再調整。
  • Logic 混音在工程內做每軌 EQ、壓縮與真實空間殘響，結果可以繼續在 Logic 編輯。
  • 兩條 branch 同時進行，聆聽比較後選定，另一條保留作為備案。
  • 逐音檢查：每個音都要有發聲，Love Beyond Reach Mvt. 1（Remix）的 Logic 版吉他 657 個音全部發聲。
  • 對位量測：人聲起音與生成曲相差 60 毫秒內的比例，主歌從 64% 提升到 75%。
  • 響度與頻段：整體響度對齊 −14 LUFS，並比較各頻段與生成曲的差距。
  • 聆聽後用小節號指出問題，從出問題的那一步重跑，不必整首重做。
  • 每一次修正都留下紀錄與當時的檔案，目前 53 筆，舊版一律不刪。
  • 不同步、歌詞沒對上、兩把吉他混成一條，都是聆聽時發現的，發現後再寫成自動檢查。
