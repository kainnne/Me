# AI 與工作

## Q：你現在用 AI 完成什麼樣的任務？

- AI 系統與應用開發
- 程式開發、測試、除錯與部署
- 文件、資料與知識庫整理
- 研究、資料分析與實驗規劃
- 教育訓練與教材製作
- Project planning 與工作流程自動化

## Q：我的 AI Agent 操作方式

- 我是 AI Agent 的重度使用者，將 Agent 作為長期開發、研究與專案執行的協作者。
- 同時維護多個長期專案，使用 `AGENTS.md`、Markdown、Project Contract、Git 紀錄與任務交接保存 context、memory、規則與目前狀態。
- 將大型目標拆成研究、實作、測試、文件與部署等可驗收任務；需要時會讓多個 Agent 平行處理獨立工作。
- 執行前提供目標、檔案範圍、不可修改項目、完成條件與既有決策，降低誤解與重工，同時減少 token 的浪費。
- 將重複流程自動化，例如建置、測試、部署、HTTPS 狀態檢查、網域設定追蹤、文件同步與知識庫維護。
- 設計嚴謹的 Loop Engineering 邏輯，在節省輸入 prompt 與專注單一任務時間的同時，確保成果在可控範圍以內。
- 設計 system prompt，讓口語化的 prompt 在方便思考的同時，也能成為精確的工作指令。
